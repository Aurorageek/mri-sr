# Phase 4 研究报告：基于原始 SMORE 的实质性方法探索

## 1. 此前简化 SMORE 与原始 SMORE 的差异

| 项 | 原论文 | 此前实现 | Phase 4 |
|---|---|---|---|
| 退化模型 | `rect(r·u)×Fermi(u;r)`，Fermi 宽度 10/L | Gaussian/Box/Fermi | **已实现 paper 对齐** |
| 网络 | EDSR | 简化 EDSR 8×64 | 仍为简化 EDSR（明确声明） |
| 旋转增强 | 7 个角度，留一验证 | 仅翻转 | **未复现** |
| 单方向推理 | M=1 为主 | 有 | 有 |
| 多方向 + FBA | M=2/7 + FBA | 无 | **已实现 M=2 FBA 对照** |

## 2. 是否建立了原论文对齐的 Baseline？

**是。** `src/degradation.py` 新增 `"paper"` 滤波器（Eq.1，PMC 全文核实），
单元测试 4/4 通过；在 IXI002/012/013/022 上训练 paper-aligned Baseline A。

**重要发现**：paper 对齐退化下，SMORE 单方向相对 Sinc 提升为
**+0.78/+0.91/+1.02/+0.89 dB**，显著大于此前 Gaussian 模拟的 +0.24~0.41 dB。
说明**报告的增益强烈依赖模拟退化模型**。

## 3. 原论文已研究过的多方向融合

- 早期工作 M=2（coronal+sagittal）；论文比较 M=1/2/7，M=7 旋转 θ=nπ/12；其余实验 M=1。
- 融合使用 FBA（频域加权自集成）。
- 结论：本项目的 M=2 Average/FBA 属复现对照，非原创。

## 4. 跨平面预测分歧是否能反映重建错误？

**部分能。** 4 名受试者一致：
- Spearman(U, |X_mean−HR|) = **0.30–0.35**，十分位误差单调上升 3–4 倍；
- 控制 Sinc 梯度/局部方差/残差幅值后，偏相关仍 **0.22–0.26**（有额外信息）。

## 5. 分歧是否提供超出简单梯度和残差幅值的额外信息？

**有限地提供。** U 与梯度相关 0.55–0.59、与局部方差 0.68–0.75、与残差幅值 0.49–0.56；
偏相关仍有 ~0.2，但大部分信息可由这些简单量解释。

## 6. 是否实现了可靠性引导的重建方法？

**是**：`X_RG = g + exp(−U/τ)·R_mean`（推理时后处理，无需重训）。

## 7. 是否优于 paper-aligned SMORE、FBA、固定残差缩放？

**否，全面劣于。**
- RG-τ0.5：29.146 / 33.559 / 34.367 / 29.938
- Average：29.675 / 34.179 / 35.047 / 30.526
- FBA：29.683 / 34.187 / 35.054 / 30.535
- 能量匹配 Fixed-α：29.204 / 33.609 / 34.416 / 29.977（**每一例都高于 RG**）

## 8. 改善来自真实细节恢复，还是仅仅保守输出？

**两者都不是**：RG 比"正确程度的保守"（能量匹配固定缩放）还差。残差分解显示，
门控把 pred² 从 70→9 的同时把 cross-term 从 157→48，残差-目标相关从 0.489 降到
0.408——**削弱了对齐**，而不是去除错误。

## 9. 是否有错误结构、过度平滑或其他副作用？

- RG/GradGate 会过度平滑（残差被过度抑制），但不引入新的伪结构。
- 简单 Average/FBA 没有新增明显伪影。
- 未出现"消除幻觉"的证据，不能如此宣称。

## 10. 是否存在高度相似的已有研究？

- **iSMORE**（Sobel edge loss + 迭代）与我们早期的 Sobel 损失高度重叠 → 不能作为原创。
- **Pushing the limits of zero-shot SSR** 探索 wavelet/FFT/对抗损失与重采样 → 简单换损失
  也非空白。
- 关于"预测分歧引导 SR"的专门文献：本轮**未完成系统检索**，正式写作前必须补查，
  不得宣称原创。

## 11. 当前方法具有什么实际研究价值？

- **负结果有价值**：跨平面分歧能描述误差大小，但不能识别有害修正；任何基于它的
  残差抑制都不如简单平均/固定缩放。
- **正值**：paper 对齐退化让 SMORE 增益从 ~0.3 dB 提到 ~0.9 dB（模拟协议的重要性）。
- **鲁棒性发现**：干净训练的 SMORE 在噪声下会**低于 Sinc**；噪声增强自监督训练以
  近乎零的干净代价修复该问题（σ_train=0.02）。

## 12. 是否值得进一步扩大实验？

- **RG 方向：不扩大（DISCARD）。**
- **噪声鲁棒方向：值得**（KEEP）。需在新受试者上与更多噪声水平验证。

## 13. 距离课程项目提交尚缺的工作

1. 噪声鲁棒方法在 **8–10 名新受试者**上的正式验证（当前仅 2 名）。

3. 英文论文正文（素材见 `PAPER_EXPERIMENTS.md`）。
4. 若选定噪声方向：补充 σ_train 的消融（0.02/0.05）与 Rician 参数说明。
