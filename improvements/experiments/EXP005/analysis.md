# EXP005：多退化鲁棒性的跨受试者验证（强正结果 KEEP）

- **Research Question**：EXP004 的多退化训练改善是否跨受试者成立？
- **Method**：4 名受试者（IXI002/012/013/016）各训练 Gaussian 与 Multi-Deg 模型，
  在 Gaussian/Box/Fermi 三种实际退化下评价，报告相对 Sinc 的 ΔPSNR。
- **Results**：

| 受试者 | 匹配(Gaussian) Δ：Gauss / MultiDeg | 失配最差 Δ：Gauss / MultiDeg |
|---|---:|---:|
| IXI002 | +0.27 / +0.41 | -1.63 / -0.00 |
| IXI012 | +0.38 / +0.45 | -2.20 / -0.02 |
| IXI013 | +0.47 / +0.47 | -2.35 / +0.00 |
| IXI016 | +0.19 / +0.29 | -1.71 / -0.17 |

- **Conclusion**：跨 4 名受试者一致——多退化训练在**匹配条件上持平或略升**，在
  **失配条件上从 -1.6~-2.4 dB 修复到 ≈0 dB**（最差情况改善约 +1.9 dB）。
- **Decision**：**KEEP（强）**。多退化自监督训练是稳健且低成本的鲁棒性改进。
- **局限**：4 名受试者，其中 IXI013/016 属已用测试集（探索性）；未测 r=4、
  更多退化类型与噪声。
