# EXP018：可靠性引导残差恢复（RG-SMORE）与严格对照——负结果

## 设置

paper-aligned checkpoint（单受试者自监督），同一 g 上做 R-A / R-S 两方向推理，
得到 X_A、X_B。对照组：

| 方法 | 定义 |
|---|---|
| Sinc | g |
| Single-A / Single-B | 单方向 |
| Average | (X_A+X_B)/2 |
| FBA | 频域 \|F\|^p 加权融合（p=3） |
| Fixed-a | g + α(X_mean−g) |
| GradGate | g + exp(−\|∇g\|/τ)(X_mean−g) |
| RG | g + exp(−U/τ)(X_mean−g)，U 平滑分歧 |
| Fixed-aEQ | 与 RG 残差能量相同的固定 α |

## 结果（PSNR dB；ΔMSE 为相对 Sinc）

| subject | Sinc | Single-A | Average | FBA | RG-τ0.5 | Fixed-αEQ | GradGate-τ0.5 |
|---|---:|---:|---:|---:|---:|---:|---:|
| IXI002 | 28.880 | 29.659 | **29.675** | **29.683** | 29.146 | 29.204 | 29.170 |
| IXI012 | 33.259 | 34.171 | 34.179 | **34.187** | 33.559 | 33.609 | 33.602 |
| IXI013 | 34.023 | 35.040 | 35.047 | **35.054** | 34.367 | 34.416 | 34.422 |
| IXI022 | 29.633 | 30.521 | 30.526 | **30.535** | 29.938 | 29.977 | 29.982 |

关键观察：

1. **Average / FBA 最好**；任何门控都降低 PSNR。
2. **RG 在每一名受试者上都差于能量匹配的固定缩放**（−0.03~−0.07 dB）。
3. 残差分解：RG 把 pred² 从 70→9，却把 cross-term 从 157→48；残差-目标相关
   从 0.489 降到 0.408。门控**同时**削弱了对齐，净收益为负。
4. 有害体素比例：Fixed-αEQ（17.0%）低于 RG（23.3%），RG 并未更有效抑制有害修正。

## 结论 / 决策

- **DISCARD**。跨平面分歧可用于描述误差大小（EXP017），但不能指导残差抑制；
  高分歧区域恰恰是残差最大也最有益的区域。
- 有价值的方法是对两个方向做简单平均/FBA，而非可靠性门控。
- 该负结果解释了"为什么 U 与有害修正不相关（ρ≈0）"的直接后果。
