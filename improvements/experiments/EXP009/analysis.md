# EXP009：保守残差分析（多退化的作用机制）

- **Research Question**：多退化训练是否只是抑制错误锐化，而非恢复额外细节？
- **Method**：SR = Sinc + α·Residual，扫描 α∈{0,0.25,0.5,0.75,1}（零训练，复用 checkpoint）。
- **Results（IXI002，ΔPSNR vs Sinc）**：

| 条件 | 方法 | α=0 (Sinc) | α=0.5 | α=1 (full) |
|---|---|---|---|---|
| Box | fixed-G | 0 | -0.41 | -1.64 |
| Box | multi-D | 0 | +0.08 | 0.00 |
| Fermi | fixed-G | 0 | -0.24 | -1.24 |
| Fermi | multi-D | 0 | +0.12 | +0.10 |

- **Conclusion**：
  1. **fixed-G 的残差在失配条件上单调有害**（α 越大越差），证明其"锐化"是错误的方向
     （放大振铃/混叠）。
  2. **multi-D 的残差接近中性**（α=1 时 ≈Sinc），在 α≈0.5–0.75 有微小峰值（+0.08~+0.13）。
  3. 因此多退化的鲁棒性主要来自**避免有害锐化**，在失配条件上并未恢复额外高频细节；
     只有在匹配（Gaussian）条件下才真正恢复细节（EXP007 中 +0.41 dB）。
- **Decision**：KEEP（机制刻画）。保守残差（α<1）有边际收益但 <0.15 dB，不单独作为方法。
