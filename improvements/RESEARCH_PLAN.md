# 研究计划

## 核心研究问题（Research Problem）

在自监督 MRI through-plane 超分辨率中，**训练时模拟的退化与推理时实际遇到的退化
之间的不一致（degradation mismatch）如何影响重建质量，以及能否通过退化算子对齐
或退化鲁棒训练改善**。

## 背景观察（Observation，Day 1–6 已确认）

1. SMORE 相对 Sinc 稳定有效（8 受试者 PSNR +0.32 dB、3D 梯度误差 -20%）。
2. Sobel Gradient Loss 相对 L1 几乎无增益（+0.007 dB），已被判为 DISCARD。
3. 训练退化 = 对 in-plane 切片做**单轴低通**；推理实际输入 = HR 经
   **低通 + 下采样 + Sinc 插值**得到的 g。两者在频域上可能不等价。

## 方向优先级

| 优先级 | 方向 | 说明 |
|---|---|---|
| **A（最高）** | 退化算子对齐 | 数值/数学分析训练退化 vs 实际退化的差异，再决定是否训练 |
| B | 退化模型失配 | D_real × D_train 3×3 矩阵（Gaussian/Box/Fermi） |
| C | 多退化鲁棒训练 | 若 B 显示明显失配现象 |
| D | 多方向重建融合 | 若退化相关改进收益有限 |
| E | 跨受试者预训练 + 个体适配 | 若单受试者自监督信息量有限 |
| F | 其他有证据的改进 | 频域一致性、不确定性、2.5D 上下文等 |

## 初始行动

1. ✅ 建立 improvements/、冻结基线、修复梯度评价指标。
2. 方向 A：数值分析（合成信号 + 真实切片）比较：
   - 训练退化（low-pass only）
   - 实际退化（low-pass + downsample + sinc）
   检查频率响应、采样相位、混叠、voxel spacing 差异。
3. 若差异显著 → 设计对齐退化训练（EXP 预实验）；若差异可忽略 → 转方向 B/D。

## 预算

- GPU 训练累计约 ≤ 8 小时，≤ 12 组新候选训练。
- 优先低成本数值分析，避免无意义训练。
